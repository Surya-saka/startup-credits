|------|---------|--------|
| For Startups | €10,000 | MVP stage |
| For Scaleups | €100,000 | Post-revenue |

- **Requirements:**

## Data Sovereignty Considerations

### GDPR Compliance
All European providers offer GDPR-compliant infrastructure:
- **OVHcloud:** French company, EU data centers
- **Scaleway:** French company, EU only
- **Open Telekom:** German company, EU data centers
- **Scalingo:** French company, EU hosting

### China Market Entry
For accessing Chinese market:
- **Tencent Cloud:** Native Chinese infrastructure
- **Alibaba Cloud:** ICP license support
- **Huawei Cloud:** China presence + global

## Application Tips

### OVHcloud
- Apply as early as possible (limited slots)
- Prepare growth metrics for Scaleups tier
- Accelerators can apply for Enablers pool

### Huawei/Tencent/Alibaba
- Consider local subsidiaries if available
- Partner with local accelerators for better access
- Prepare for longer approval processes

### European Programs
- Emphasize EU data residency needs
- Highlight GDPR compliance requirements
- Mention any EU customer base

| OVHcloud + AWS | €100K + $100K |
| Scaleway + GCP | €42K + $200K |

**Tip:** Use regional programs for data residency requirements, global programs for scalability.

## Regional Program Checklist

Before applying to regional programs:

- [ ] Verify company registration in target region (if required)
- [ ] Understand data residency requirements
- [ ] Check language support for documentation
- [ ] Confirm billing currency preferences
- [ ] Research regional compliance requirements
- [ ] Identify local accelerator partnerships
