## Project Management

### Linear Startup Program
- **Value:** 100% off (6 months)
- **Eligibility:**
  - <50 employees
  - New to Linear paid plans
  - Partner-affiliated (accelerator/VC/incubator)
- **Features:**
  - Cycles for sprint planning
  - Projects for roadmaps
  - Custom workflows
  - GitHub, Figma, Slack integrations
- **Process:**
  1. Get partner code from accelerator/VC
  2. Submit via Linear (as admin)
  3. Upgrade to paid plan
- **Post-Program:** $10/user/month

## Team Size Recommendations

### Solo/Small Team (1-5)
- **Docs:** Notion Tier 2
- **Tasks:** Linear or ClickUp
- **Whiteboard:** Miro

### Growing Startup (5-25)
- **Docs:** Notion Tier 1
- **Engineering:** Linear
- **Company-wide:** Asana or ClickUp
- **Collaboration:** Miro + Airtable

### Scale-up (25-50)
- **Suite:** Atlassian (Jira + Confluence)
- **Whiteboard:** Miro
- **Database:** Airtable
