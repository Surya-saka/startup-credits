# Major Cloud Providers

The primary hyperscale cloud providers offering comprehensive infrastructure services.

---

## AWS (Amazon Web Services)

### AWS Activate Founders
- **Credits:** $1,000
- **Duration:** 2 years
- **Eligibility:**
  - Founded within the last 10 years
  - Fully-functioning company website
  - Self-funded or pre-Series B
  - Not previously received equal/greater AWS credits
- **How to Apply:**
  1. Create an AWS Builder ID
  2. Complete application at [aws.amazon.com/startups/credits](https://aws.amazon.com/startups/credits)
- **What's Included:** Credits for 100+ AWS services

### AWS Activate Portfolio
- **Credits:** Up to $100,000
- **Duration:** 2 years
- **Eligibility:**
  - Associated with an Activate Provider (VC, accelerator, incubator)
  - Same requirements as Founders tier
- **How to Apply:**
  1. Request Organization ID from your Activate Provider
  2. Apply at [aws.amazon.com/activate/portfolio-detail/](https://aws.amazon.com/activate/portfolio-detail/)
- **Tiers:** Launchpad, Orbital, Stellar, Galactic (based on company stage)

### AWS Rapid Ramp
- **Credits:** $300
- **Link:** [aws.amazon.com/startups/](https://aws.amazon.com/startups/)

## Microsoft Azure

### Azure Free Trial
- **Credits:** $200
- **Duration:** 30 days
- **Link:** [azure.microsoft.com/free/](https://azure.microsoft.com/free/)

### Microsoft Founders Hub
- **Credits:** Up to $150,000 (tiered)
- **Duration:** 12 months per tier

| Level | Credits | Requirements |
|-------|---------|--------------|
| L1 | $1,000 | New applicants |
| L2 | $5,000 | Used ~50% of L1 credits |
| L3 | $25,000 | Functional MVP, substantial L2 usage |
| L4 | $150,000 | Demonstrated scaling, customer demand |

- **Eligibility:**
  - Privately held, for-profit
  - Software-based product
  - <$10k prior Azure credits used
  - Pre-Series D stage
- **How to Apply:** [foundershub.startups.microsoft.com](https://foundershub.startups.microsoft.com/)
- **What's Included:**
  - Unlimited 1:1 engineer sessions
  - Free Teams, GitHub Enterprise
  - Azure OpenAI Service access
  - GPU VM access (L3+)
  - Co-selling opportunities (L4)

## Google Cloud Platform (GCP)

### GCP Free Trial
- **Credits:** $300
- **Duration:** 90 days
- **Link:** [cloud.google.com/free](https://cloud.google.com/free)

### Google Cloud for Startups - Start Tier
- **Credits:** $2,000
- **Duration:** 12 months
- **Eligibility:**
  - Not yet institutionally funded
  - Founded within 5 years
  - No prior GCP credits beyond free trial
- **What's Included:**
  - $200 Skills Boost training credits
  - Technical support
  - Google Workspace Business Plus (12 months free)
- **Link:** [cloud.google.com/startup](https://cloud.google.com/startup)

### Google Cloud for Startups - Scale Tier
- **Credits:** Up to $200,000 ($100K Year 1 + 20% up to $100K Year 2)
- **Duration:** 2 years
- **Eligibility:**
  - Pre-seed through Series A funding
  - Founded within 10 years
  - <$5,000 prior GCP credits
- **What's Included:**
  - $500 Skills Boost credits
  - $12,000 Enhanced Support credits
  - Startup Success Manager
  - Co-marketing opportunities
- **Link:** [cloud.google.com/startup](https://cloud.google.com/startup)

## IBM Cloud

### IBM for Startups
- **Credits:** Up to $120,000
- **Duration:** 12 months
- **Cost:** Free, no equity required
- **Eligibility:**
  - Revenue <$15M in last 12 months
  - Privately held, <10 years old
  - Not currently paying IBM Cloud customer
  - Verifiable entity with website
- **What's Included:**
  - Access to 170+ IBM products (AI, IoT, data tools)
  - Expert mentorship
  - Enterprise presentation opportunities
  - Platform support for scaling
- **Link:** [ibm.com/startups](https://www.ibm.com/startups)
