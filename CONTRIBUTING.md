# Contributing

Thanks for your interest in contributing to the Startup Cloud Credits Guide!

---

# How to Contribute

1. Fork the repository
2. Create a branch for your changes
3. Make your changes
4. Submit a pull request

---

# What We're Looking For

- New cloud credit programs not yet listed
- Updates to existing program details (credit amounts, eligibility, links)
- Corrections to broken or outdated links
- Additional tips or guides

---

# Submission Guidelines

When adding a new program, please include:

- Provider name
- Program name
- Credit amount or discount percentage
- Eligibility requirements
- Official application link (direct to provider, not third-party)
- Category it belongs to

---

# Verifying Information

Before submitting, please verify:

- The program is currently active
- The application link works
- Credit amounts are accurate
- Eligibility requirements are current

---

# Code of Conduct

Be respectful and constructive in all interactions.
