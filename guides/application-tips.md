# Application Tips

Best practices for applying to cloud credit programs.

---

## Before You Apply

### 1. Prepare Your Materials

**Essential Documents:**
- Company pitch deck (2-10 slides)
- Company website (must be live)
- Business email (not gmail/yahoo)
- LinkedIn company page
- Brief product description

**For Premium Programs:**
- Funding documentation
- Technical roadmap
- Team information
- Accelerator/VC affiliation proof

### 2. Set Up Accounts First

Many programs require an existing account:

```
1. Create free account with provider
2. Verify email and add payment method
3. Then apply to startup program
```

**Why:** Programs often apply credits to existing accounts.

## Writing Effective Applications

### Product Description

**Bad:**
> "We're building an AI platform."

**Good:**
> "We're building an AI-powered customer support platform that reduces response time by 80% using GPT-4 for ticket classification and automated responses. Currently serving 50 beta customers with 10K monthly tickets processed."

### Technical Needs

**Bad:**
> "We need cloud credits for our app."

**Good:**
> "We need compute for model training (GPU instances), managed Kubernetes for our microservices architecture, and object storage for user-uploaded documents. Expected monthly spend: $15K scaling to $50K in 12 months."

## Common Rejection Reasons

### 1. Website Issues
- No website
- Coming soon page
- No clear product description
- Broken links

**Fix:** Launch a simple landing page explaining your product.

### 2. Email Domain
- Using gmail.com
- Using personal email
- Mismatched domains

**Fix:** Use email matching your website domain.

### 3. Eligibility Mismatch
- Too much funding raised
- Company too old
- Already using competitor
- Previous credits received

**Fix:** Read requirements carefully before applying.

### 4. Incomplete Application
- Missing fields
- Vague descriptions
- No use case explanation

**Fix:** Complete every field thoroughly.

## Follow-Up Strategy

### Timing
- Wait 1-2 weeks after applying
- Send one polite follow-up email
- Include application reference number

### Follow-Up Template

```
Subject: Startup Program Application Follow-Up - [Company Name]

Hi [Program Name] Team,

I submitted an application for [Program Name] on [Date] and wanted to
follow up on the status.

Company: [Name]
Application Date: [Date]
Reference/Email: [Your application email]

Brief reminder: [1 sentence about your company]

Please let me know if you need any additional information.

Best regards,
[Name]
[Title]
[Company]
```

## After Approval

### 1. Activate Credits Immediately
- Some programs have activation deadlines
- Credits may not auto-apply
- Follow activation instructions carefully

### 2. Set Up Billing Alerts
- Monitor credit usage
- Set alerts at 50%, 75%, 90%
- Avoid unexpected charges

### 3. Track Expiration
- Most credits expire in 12 months
- Mark calendar reminders
- Plan usage accordingly

### 4. Explore Tier Upgrades
- Azure: Progress through L1-L4
- AWS: Move from Founders to Portfolio
- Use credits to justify upgrades

## Provider-Specific Tips

### AWS Activate
- Get Org ID from accelerator FIRST
- Portfolio tier >> Founders tier
- Apply through accelerator portal if available

### Azure Founders Hub
- Start at L1, progress through tiers
- Document Azure usage for upgrades
- Schedule 1:1 with Azure engineers

### Google Cloud
- Scale tier requires funding proof
- Skills Boost credits are separate
- Apply for AI program if AI-focused

### Cloudflare
- Workers Launchpad has VC connections
- R2 tier is easier to get
- Good for any startup

### DigitalOcean Hatch
- Partner affiliation required
- GPU credits are limited
- Apply early in program cycles

## Negotiation Tips

For larger programs or special circumstances:

### When to Negotiate
- You're a high-growth company
- You have unique technical needs
- You're switching from a competitor
- You have strong accelerator backing

### How to Ask
- Be specific about your needs
- Quantify your growth potential
- Mention competitor alternatives
- Ask about extended terms, not just more credits

### Example Script
> "We're currently evaluating [Competitor] as well. Our technical architecture would benefit from [specific services]. Given our growth trajectory of [metrics], we're wondering if there's flexibility on the credit amount or duration."

---

## Red Flags to Avoid

### Don't:
- Apply to programs you're not eligible for
- Lie about funding or metrics
- Use credits for non-business purposes
- Share credits with other companies
- Create multiple accounts for more credits

### These Can Result In:
- Application rejection
- Credit revocation
- Account suspension
- Blacklisting from future programs
