## Category Stacking Rules

### Cloud Infrastructure
You CAN use multiple cloud providers simultaneously:
- AWS for core compute
- GCP for AI/ML workloads
- Azure for enterprise integrations
- Cloudflare for edge/CDN

### Databases
Stack different database types:
- MongoDB (document)
- Neon (Postgres)
- Redis (cache)
- Pinecone (vector)

### Analytics
Combine complementary tools:
- PostHog (product analytics)
- Segment (CDP)
- Grafana (infrastructure)

### AI/ML
Use specialized providers:
- GCP for training
- Nebius for inference
- Deepgram for speech
- AssemblyAI for transcription

---

## Exclusivity Rules

### What You CANNOT Stack

1. **Same Provider, Multiple Programs**
   - Only one AWS Activate tier at a time
   - Only one Azure Founders Hub level
   - Choose GCP Start OR Scale (not both)

2. **Competing Tools**
   - Pick ONE primary analytics tool
   - Pick ONE primary CRM
   - Pick ONE primary project management tool

3. **Previous Credits**
   - Most programs exclude previous credit recipients
   - Check "not previously received" requirements

## Common Mistakes

### 1. Applying Too Late
- Apply before you need credits
- Some programs take weeks to approve

### 2. Not Reading Requirements
- Check funding limits
- Check company age limits
- Check prior credit exclusions

### 3. Forgetting Expiration
- Most credits expire in 12 months
- Plan workloads accordingly
- Don't hoard credits

### 4. Over-Committing
- Don't apply to competing tools
- Choose your stack thoughtfully
- Consider vendor lock-in

### 5. Missing Partner Benefits
- Join accelerators/communities first
- Then apply to partner programs
- Significant value difference
