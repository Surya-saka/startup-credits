# Tips for Maximizing Credits

1. Stack Programs - Many credits can be combined (e.g., AWS + MongoDB + PostHog)
2. Apply Early - Some programs have limited slots or require partner affiliation
3. Partner Up - Join accelerators/incubators for access to exclusive tiers
4. Track Expiration - Most credits expire in 12 months
5. Document Usage - Keep records for tier upgrades and renewals
